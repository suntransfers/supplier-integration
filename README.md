# Suntransfers Supplier Integration

Docs and resources for Suppliers to successfully integrate with Suntransfers systems.

## Supplier Hub Booking Events API (push model)

OpenAPI 3.0 spec (Swagger) and docs available at [Booking Events API Integration Guide](https://suntransfers.github.io/supplier-integration/v1/booking-events/docs/).

## Supplier Hub Full Integration

OpenAPI 3.0 spec (Swagger) and docs available at [ST SPEC: Suntransfers Supplier API Specification (v1)](https://suntransfers.github.io/supplier-integration/v1/full-integration/docs/).
If you prefer _Swagger UI_, you can access it [here](https://suntransfers.github.io/supplier-integration/v1/full-integration/try-it-out/).
